# Support

Choose a channel based on what the report contains.

## Private support

Use the [private support form](https://thetimeline.cc/help/support) or email
[contact@thetimeline.cc](mailto:contact@thetimeline.cc) for:

- account, team, sales, or billing questions;
- bugs that require account or customer context;
- screenshots or logs that cannot be made fully public; and
- any report containing personal data, customer content, credentials, invite
  links, signed URLs, or other sensitive information.

The form may attach a coarse app-surface category, an error reference, the
deployed release, and browser information. When you are signed in, it may also
attach your Timeline account ID, active team ID, and role. It never attaches
workspace content automatically. The IP address used for abuse prevention is
not saved with the support request.

## Public bug reports

Use the [bug report form](https://github.com/timborovkov/the-timeline-ai/issues/new?template=bug_report.yml)
for a reproducible, non-sensitive defect. Use only your own or synthetic data.
Remove customer content, personal data, credentials, tokens, invite links,
private URLs, and identifiers before posting.

## Security vulnerabilities

Follow [SECURITY.md](./SECURITY.md). Never disclose an unpatched vulnerability or
working exploit in a public issue or pull request.

## Contributions

Read [CONTRIBUTING.md](./CONTRIBUTING.md) before proposing work. Start with the
[contribution proposal form](https://github.com/timborovkov/the-timeline-ai/issues/new?template=contribution_proposal.yml)
and wait for maintainer agreement before substantial implementation or a pull
request.
