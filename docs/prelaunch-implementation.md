## Pricing and cancellation decision — 3 November 2026

User instructed using actual Polar metering and comparable Lovable/Recall terms. Repository `polar-setup.ts` defines the AI meter `timeline_ai_eur_cents` at one euro cent per reported unit: Timeline computes the charge; Polar does not independently price tokens. Customer copy therefore describes variable AI usage in euros, allowances, recorded charges and caps without publishing the internal multiplier. This is source verification, not a live Polar-account inspection.

Sources consulted: [Lovable credits and usage](https://docs.lovable.dev/introduction/credits-and-usage), [Lovable terms](https://lovable.dev/terms), [Recall.ai terms](https://www.recall.ai/terms-of-use). Adapted the general non-refundable-fees rule with mandatory-law exceptions, cancellation before renewal and a billing-error correction route. Did not import credits/rollover rules, annual offers or another vendor's jurisdiction. Terms/Privacy versions bumped for the material edits; no production publication flag changed. Existing counsel/publication evidence requirements remain operational follow-up, not a claim of legal approval.
