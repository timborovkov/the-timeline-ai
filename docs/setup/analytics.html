Analytics setup

SetupLast updated 2026-06-02

PostHog Cloud EU is the default product analytics and feature flag service.

Product analytics are explicit lifecycle events only. The app does not auto-track clicks, page views, session replay, prompts, transcripts, filenames, or uploaded content.

1. Project

  1. Create a PostHog Cloud EU project.
  2. Copy the project API key.
  3. Set the EU ingestion host.
NEXT_PUBLIC_POSTHOG_KEY=phc_...
NEXT_PUBLIC_POSTHOG_HOST=https://eu.i.posthog.com

2. Events

The typed event map lives in packages/shared/src/analytics/events.ts. Every event has an owner, trigger, no-PII policy, and retention note. Add new events there before emitting them from web or worker code.

Allowed payloads: stable user/team/object IDs, enum-like sources/types/statuses, counts, durations, booleans, and model IDs. Disallowed payloads: emails, names, prompts, generated answers, transcripts, document text, filenames, cookies, auth headers, and uploaded content.

3. Feature flags

Feature flags are typed in the same analytics contract. Each flag must have an owner and a cleanup note. Do not leave feature flags as permanent configuration.
