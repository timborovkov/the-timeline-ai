# Workspace reconciliation is artifact-centered and approval-backed

Workspace Reconciliation keeps approvals, workspace objects, tasks, calendar
events, and other impact context mutually consistent as newer timeline evidence
arrives. Reconciliation is anchored on inferred Artifact Clusters rather than
raw conversations, may automatically supersede pending approvals, and creates
approval-backed correction or lifecycle proposals for canonical state unless an
authoritative source updates the artifact it owns. This preserves immutable raw
events and human control over durable workspace state while reducing stale
approval noise.
