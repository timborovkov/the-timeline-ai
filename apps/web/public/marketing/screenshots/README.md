# Product screenshots

Place the Product Screenshots files named in the website copy plan here, using the exact filenames (for example `11-timeline-dark.png`).

Marketing pages look up each file by name. If a file is missing, the page shows a labeled placeholder with that filename so the slot stays easy to swap.

Do not commit customer data. The committed set is from a fresh fictional Acme Labs `demo:seed` on current main (numbered citations and relative demo dates).
