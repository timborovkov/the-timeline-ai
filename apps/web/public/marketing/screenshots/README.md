# Product screenshots

Place the Product Screenshots files named in the website copy plan here, using the exact filenames (for example `11-timeline-dark.png`).

Marketing pages look up each file by name. If a file is missing, the page shows a labeled placeholder with that filename so the slot stays easy to swap. `screenshot-inventory.test.ts` also fails when any referenced public marketing file is absent, so a missing asset cannot ship as a silent placeholder.

Do not commit customer data. The committed set is from a fictional Acme Labs `demo:seed` capture (November 2026 numbered citations). Ask screenshots are stored seed answers, not live generated proof. Keep the fictional-example label on every public product shot.
